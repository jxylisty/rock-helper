壹

全局策略：三层改造法

与首页样板相同的方法论：底层组件先行，页面只做「换壳 + 换图标」，业务逻辑零改动。

第一层 · 组件

共享组件贴纸化

PetCard（图鉴 / 技能查询共用）升级为贴纸卡 + 属性色顶边条 + 编号等宽字 + 描金角标；TypeBadge 加 1px 白描边与硬阴影，升级为「印记」质感；AppHeader 补齐金 / 蓝 / 红三个新主题。

第二层 · 框架

每页一个主题色

头栏渐变色按页面职能分配：绿 = 资料库（图鉴 / 阵容）、金 = 培养工具（孵蛋 / 技能）、蓝 = 探索（地图 / 速度）、红 = 战斗（克制 / 伤害）。页面底色统一羊皮纸，卡片统一贴纸规格。

第三层 · 页面

逐页换壳 + 图标化

每页替换：纸底背景、贴纸卡片、AppIcon 图标按钮（替换 + − × ▼ ▶ → 等文字符号）、按压反馈。详情页与伤害计算页需在 pages.json 切换为 custom 导航后接入主题头栏。
