# PVP断点分析功能设计

## 功能目标

PVP断点分析不是普通阵容评分，而是帮助玩家回答：

1. 当前精灵应该加速度、输出，还是肉度？
2. 加速度能不能超过关键目标？
3. 不加输出会不会少秒某些精灵？
4. 把 +10 资质分配到生命、物防、魔防是否能多扛一次？
5. 当前技能打目标能造成多少伤害？
6. 目标精灵的常见技能打我方能造成多少伤害？
7. 强化一次后能不能跨过伤害线？
8. 减伤后能不能扛住关键技能？

## 页面模式

PVPBreakpointPanel 使用三种模式：

### 1. 我打谁

用户选择：
- 我方配置
- 我方技能
- 目标精灵
- 目标配置

展示：
- 基础伤害
- 启用条件后的伤害
- 伤害 / 生命 / 百分比 / 差值或溢出

### 2. 谁打我

用户选择：
- 我方配置
- 敌方精灵
- 敌方技能
- 敌方配置

展示：
- 基础受到伤害
- 启用防御条件后的受到伤害
- 多个敌方输出技能的伤害列表
- 受到伤害 / 自身生命 / 百分比 / 剩余或溢出

### 3. 配置推荐

展示 5 个代表性配置：
- 极速
- 物攻
- 魔攻
- 物耐
- 魔耐

不展示大量表格，只展示当前技能、当前目标下的关键变化。

## 技能选择设计

技能必须由用户选择。

默认技能列表只展示紧凑信息：
- 技能名
- 属性
- 类型
- 威力
- 有效威力
- 能耗

点击详情按钮弹出小窗口。

技能描述不在列表中展开。

## 常见技能筛选

commonSkillPresets.json 用于：
- 设置常见有效威力阈值
- 设置某些精灵的常用技能排序
- 选择默认技能

它不能改变公式，不能增加额外 BUFF。

默认：
- minEffectivePower = 80
- 谁打我模式默认展示敌方 effectivePower >= 80 的输出技能
- 可以提供“显示全部输出技能”开关

petOverrides 只用于置顶常用技能，不改变筛选和伤害公式。

## 条件预设设计

条件预设来自当前精灵自己的技能或特性。

常见预设：
- 力量增效：物攻 +100%
- 魔法增效：魔攻 +70%
- 啮合传递：速度 +80
- 啮合传递：物攻 +60%
- 防御技能：减伤 50% / 60% / 70% / 80% / 90% / 100%
- 若先于敌方攻击，威力 +X%

所有预设默认不启用。

启用后必须同时保留基础结果。

## 迅捷处理

迅捷只作为切换机制标签。
不要作为先手+1。
不要影响 canActBeforeEnemy 的 priority 判断。
