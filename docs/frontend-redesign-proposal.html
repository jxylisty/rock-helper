壹

现状诊断

通读 App.vue 设计变量、pages/index.vue 及核心组件后，总结出五个与「洛克王国」气质脱节的核心问题。

气质错位

商务灰绿，不像洛克王国

白底 + Slate 灰阶 + #22C55E 是标准 ToB 后台风。洛克王国的世界观是魔法学院与精灵探险，界面却没有一丝游戏感与温度。

图标缺失

用文字符号充当图标

导航用 ☰、返回用 ←、折叠用 ⌄、添加用 +。跨设备渲染粗细不一，且无任何语义装饰，全 App 没有一枚真正的图标。

层级扁平

卡片同质、视觉无节奏

所有卡片统一「白底 + 1px 灰边 + 8px 圆角 + 微阴影」，hero、阵容卡、快捷入口、空状态长得几乎一样，扫视时抓不到重点。

规范漂移

设计令牌存在但未执行

App.vue 定义了完整 CSS 变量体系，页面里却大量硬编码色值；rpx 与 px 混用（同一弹窗内 26rpx 与 13px 并存），多端一致性存疑。

交互生硬

反馈只有 opacity 变化

所有可点元素仅有 hover-class 透明度变化，无按压位移、无展开动画、无空状态插画，弹窗与抽屉缺少进出场过渡。

色彩浪费

十八属性色未成体系

项目已维护草/水/火/电等 18 系属性配色，但只用于小徽章文字底色。这套最有「图鉴感」的资产没有放大成界面的视觉语言。

贰

设计方向

为「查数据的老玩家」而非低龄用户设计：保留工具的冷静密度，注入魔法世界的温度。

DESIGN DIRECTION
魔法图鉴绘本
The Grimoire Sticker-Book

图标方案选型

硬性约束：App 主打「本地离线」，图标必须打包进安装包、不依赖任何 CDN 或运行时网络。三个候选对比如下。

方案离线可用uni-app 兼容风格匹配接入成本体积
iconfont 字体图标
阿里巴巴矢量图标库		 字体文件打进 static font-class 方案全端通吃 可自选圆润卡通风图标 低 · 建 iconfont 项目下载引入 按需定制，约 20–40KB

推荐：iconfont 字体图标 + 自建 <AppIcon> 组件

实施路线

三阶段推进，每阶段结束都是可运行、可回退的完整版本。

阶段一 · 地基
  • 建 iconfont 项目，选齐导航 / 操作 / 属性图标，字体落盘 static/fonts/
  • 封装 AppIcon.vue 组件（name / size / color 三 props）
  • App.vue 重写设计令牌：新色板、圆角、贴纸阴影变量，统一 px 单位策略
  • 全局样式：页面纸底、按钮按压态、胶囊徽章工具类
阶段二 · 骨架
  • 改造 AppHeader（渐变 + 图标钮 + 状态胶囊）
  • 改造 SideDrawer（图标菜单 + 分组 + 进出场动画）
  • 改造 TypeBadge（胶囊印记化）、PetCard（贴纸卡 + 属性顶条）
  • 新增 底部 TabBar 组件，接入首页
阶段三 · 逐页
  • P1 四页：index / catalog / detail / team-editor
  • P2 四页：restriction / skill-search / speed-rank / pvp-breakpoint
  • P3 两页：egg / map
  • 全量回归：Android 真机 + H5 双端检查 rpx 换算与滚动性能
风险与对策

① iconfont 字体在部分低版本 Android WebView 首帧闪烁——用 font-display: block + 预加载规避；② 贴纸硬阴影在长列表滚动时的性能——阴影只用 box-shadow 偏移（无 blur），GPU 开销极低；③ 改动面大——每阶段独立提交，出问题可按组件粒度回退，不动任何业务逻辑与数据层。
